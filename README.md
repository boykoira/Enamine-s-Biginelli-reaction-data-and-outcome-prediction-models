# 🧪Enamine's Biginelli reaction data and outcome prediction models

This repository contains Enamine's Biginelli reaction data, both raw and curated, and three reaction outcome prediction models with associated files and descriptions, as part of the Supplementary Information for our paper:

**Predicting Reactivity and Reaction Yields in Parallel Synthesis: Meeting of Expectations and Reality**

[ChemRxiv preprint](https://chemrxiv.org/doi/full/10.26434/chemrxiv.15000783/v1)

\---

## 📖Overview

The project focuses on the Biginelli reaction as a case study for evaluating how real-world experimental data quality affects the performance, reliability, and practical applicability of predictive models in synthetic chemistry.

The repository includes:

* raw experimental reaction data;
* curated datasets prepared for modeling;
* three reaction outcome prediction models for a consensus prediction;
* scripts and descriptions for making an external prediction.

\---

## 📦Repository contents

```text
/data
    Raw and curated Biginelli reaction datasets.

/models
    Trained reaction outcome prediction models.

```

\---

### Data

The data folder contains Enamine's Biginelli reaction data used in the study. Both raw and curated versions are provided to support transparency and reproducibility.

The curated datasets were prepared for machine learning workflows as described in the paper and supplementary information.

\---

### Models

The repository contains three trained reaction outcome prediction models used to predict the external test set, as described in the publication. Additional files, necessary for data preprocessing and descriptor calculation, are provided.

### Code and scripts

Please refer to the comments and descriptions in the corresponding directories for usage details.
